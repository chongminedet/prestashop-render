PrestaShop Cloud Deployment

Decoupled, free-tier e-commerce architecture — web tier and database hosted independently.

🌐 Web Tier — Render (Free)

  • Image: prestashop/prestashop:8-apache
  • Runtime: Apache + PHP 8.2
  • Admin path: /admin-panel
  • Filesystem: ephemeral — config regenerated from env on every boot

🗄️ Database — alwaysdata (Free)

  • Engine: MariaDB 10.11
  • Access: public TCP proxy, port 3306
  • Storage: 1 GB SSD, daily backups
  • Decoupled: never runs on the web instance

🔗 Architecture

  • Storefront: prestashop-render.onrender.com
  • Flow: Render edge → Apache/PHP → MariaDB over WAN
  • CI/CD: GitHub → Render auto-deploy on push
  • TLS: automatic HTTPS at Render's edge
